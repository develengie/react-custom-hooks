# Задание 1

Реализуйте хук useFetch(), который можно будет использовать следующим образом:

```javascript
import { useFetch } from './useFetch';

function Demo() {
  const {
    data,
    isLoading,
    error,
    refetch
  } = useFetch('https://jsonplaceholder.typicode.com/posts');

  return (
    <div>
      <div>
        <button onClick={() => refetch({
          params: {
            _limit: 3
          }
        })}>
          Перезапросить
        </button>
      </div>
      {isLoading && 'Загрузка...'}
      {error && 'Произошла ошибка'}
      {data && !isLoading && data.map(item => <div key={item.id}>{item.title}</div>) }
    </div>
  );
}
```

Хук useFetch() принимает url, по которому можно совершить запрос к удаленному серверу и возвращает объект со следующими данными:

-   data - массив с полученными данными;
-   isLoading - булевое значение, отображающее состояние загрузки;
-   error - строка, содержащая текст потенциальной ошибки;
-   refetch - функция совершения повторного запроса по url, принимающая объект с query-параметрами.

Запрос к удаленному серверу совершается с помощью асинхронной функции fetchData(), вызывающейся в момент монтирования компонента. Работа функции позволяет управлять значениями переменных isLoading и error.<br>
Повторный запрос к удаленному серверу совершается с помощью функции refetch(), вызывающейся при нажатии на кнопку. Функция позволяет получить первые N элементов получаемого массива данных, исходя от передаваемого в нее параметра _limit.<br>
Типизированы параметры функции refetch(), получаемый массив данных и ее элемент в отдельности.
