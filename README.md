# Задание 3

Реализуйте хук useHover(), который можно будет использовать следующим образом:

```javascript
import { useHover } from './useHover';

function Demo() {
  const { hovered, ref } = useHover();

  return (
    <div ref={ref}>
      {hovered ? 'На меня навели мышку' : 'Наведи мышкой на меня'}
    </div>
  );
}
```

Хук useHover() возвращает объект со следующими данными:

-   hovered - булевое значение, отображающее, наведен ли курсор на элемент \<div\>;
-   ref - ссылка на элемент \<div\>.

Управление сменой текста внутри элемента \<div\> выполняется с помощью функции changeTextContent(), вызывающейся в момент монтирования компонента. В ней происходит слушание событий наведения (mouseover) и отведения курсора (mouseout).<br>
Типизированы возвращаемые хуком данные.
