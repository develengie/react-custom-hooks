# Дополнительное задание 2

В этом задании необходимо усложнить хук useToggle(). Теперь он должен принимать массив значений, которые будут переключаться по порядку. Если ничего не передавать, то будет переключать между true и false. Хук может использоваться следующим образом:

```javascript
import { useToggle } from './useToggle';

function Demo() {
  const [value, toggle] = useToggle(['blue', 'orange', 'cyan', 'teal']);

  return (
    <button onClick={() => toggle()}>
      {value}
    </button>
  );
}

// Еще примеры использования

const [value, toggle] = useToggle(['light', 'dark']);

toggle(); // -> value === 'light'
toggle(); // -> value === 'dark'

// Так же можно передать конкретное значение и тогда
// value станет одним из значений
toggle('dark'); // -> value === 'dark'
```

Для реализации был использован хук useReducer(), принимающий функцию reducer() и начальное состояние initialState, представляющее собой индекс первого элемента массива, т.е. initialState равняется нулю. useReducer() возвращает индекс элемента массива, на который произошло переключение и dispatch, в который отправляются объекты с типами TOGGLE и SET, исходя из того, принимает ли useToggle() массив значений или нет.
Хук useToggle() принимает массив значений, либо не принимает ничего и возвращает кортеж со следующими данными:

-   createArray()[index] - функция, позволяющая получить элемент из массива значений, на который произошло переключение;
-   toggle - функция, управляющая переключением между значениями, с которыми работает useToggle().

Типизированы структура action, возвращаемые хуком useToggle() данные и принимаемые функциями reducer() и toggle() параметры.
